# 🎯 Funcionalidades Implementadas

Funcionalidade individual desta branch:

### ✔️ Funcionalidade 10 — Tela de Game Over com pontuação final
- Tela dedicada de Game Over  
- Pontuação final exibida ao jogador  
- Reinício do jogo com **R**  
- Saída do jogo com **ESC**  

Outras funcionalidades implementadas pelo grupo:
- Power-up de vida  
- Power-up de velocidade  
- Power-up especial  
- Sistema de pausa (**P**)  
- Aumento gradual da velocidade dos meteoros  
- Sons (pontuação, colisão, power-up)  
- Música de fundo  
- Background personalizado  
- Múltiplos tipos de meteoros  
- Mecânica de vidas

# 🖥️ Como instalar

### 1. Instalar dependências
Requer **Python 3.8+** e **Pygame**:

pip install pygame
▶️ Como rodar o jogo
Clone o repositório:

git clone https://github.com/agatatg/SpaceEscapeGame.git
cd SpaceEscapeGame

Execute:
python spaceScape.py

🎮 Controles do Jogo

← / → — mover nave
P — pausar/despausar
R — reiniciar na tela de Game Over
ESC — sair do jogo (Game Over)

🕹️ Dinâmica do Jogo

Esquive meteoros para ganhar pontos
Três colisões reduzem vidas
Power-ups:
🟩 Verde: vida extra
🟦 Azul: aumento temporário de velocidade
🟨 Amarelo: efeito especial do grupo
